## 🚀 Featured Projects

### 1. SkillSync – Placement Preparation System

A web-based platform designed to help students prepare for campus placements through structured assessments, performance tracking, and preparation roadmaps.

**Key Features:**
- Student dashboard and profile management.
- Technical and aptitude assessments.
- Performance reports and attempt history.
- Personalized preparation roadmaps.
- Placement guidance and company suggestions.
- Admin dashboard and question management.
- JWT authentication and Razorpay Test Mode integration.

**Technologies:** HTML, CSS, Vanilla JavaScript, Node.js, Express.js, MongoDB, JWT, Razorpay.

- [Live Project](https://skillsync-placement-preparation-system.onrender.com)
- [GitHub Repository](https://github.com/prernagoswami05/SkillSync-Placement-Preparation-System)

### 2. BiteVerse – Online Food Delivery Platform

A responsive food delivery web application featuring restaurant discovery, food menus, search, cuisine filtering, and interactive cart management.

**Key Features:**
- Restaurant discovery and search.
- Cuisine-based filtering.
- Food menu browsing.
- Interactive cart and quantity management.
- Dynamic billing and tax calculations.
- Order placement using REST APIs.

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Mongoose.

### 3. LifeArchive – Personal Memory Map

A personal memory management application designed to organize and preserve memories in a structured way.

**Key Features:**
- Create, view, update, and delete memories.
- Image uploads.
- Search and category filtering.
- Sorting and memory organization.
- REST API integration.
- Local JSON persistence as a database fallback.

**Technologies:** React, TypeScript, Node.js, Express.js, MongoDB.

## 💻 Run Locally

This portfolio is built using HTML, CSS, and Vanilla JavaScript.

1. Clone the repository:

   ```bash
   git clone https://github.com/prernagoswami05/prerna-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd prerna-portfolio
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.

No additional framework or backend server is required for the portfolio website.
