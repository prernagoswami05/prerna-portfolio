Project Case Study

SkillSync — Architecture & Implementation Overview

Problem Statement

College students preparing for campus placements frequently rely on fragmented notes, disconnected quiz links, and unguided topic lists without clear diagnostic feedback or a single structured workflow.

Solution

Built SkillSync as a unified placement preparation platform that brings assessments, performance analysis, structured roadmaps, company suggestions, and placement guidance into one browser-based portal.

Application Modules

11 integrated modules: Student Dashboard, 5-mode Assessment Engine, Performance Reports, Assessment Attempt History, Placement Mentor, Preparation Roadmap, Company Suggestions, Placement Guide, Student Profile, Admin Dashboard, and Super Admin functionality.

Technology Stack

HTML5, CSS3, and Vanilla JavaScript for the responsive client interface; Node.js, Express.js, and REST APIs powering server-side routing and business logic.

Authentication

Role-separated Student, Admin, and Super Admin access secured with JSON Web Tokens (JWT) and bcryptjs password hashing.

Razorpay Integration

Monthly and quarterly subscription plans implemented with Razorpay Orders API, Checkout, server-side HMAC SHA-256 signature verification, Webhooks, and MongoDB transactions (tested in Razorpay Test Mode).

Database

MongoDB Atlas connected via the native MongoDB Node.js Driver for storing student profiles, assessments, attempt histories, and transactional subscription records.

Deployment

Deployed live on Render with version-controlled source code hosted on GitHub.

Problem Statement

Understanding how real food-ordering platforms connect dynamic menu data, cart updates, and checkout flows without relying on heavy frontend frameworks.

Project Objective

Build an end-to-end browser-based food delivery app using plain HTML, CSS, and JavaScript connected to a Node.js, Express.js, and MongoDB Atlas backend.

My Contribution

Built the responsive frontend interfaces, cart and checkout interactions in vanilla JavaScript, backend API routes, MongoDB Atlas menu fetching, and Render deployment.

Technology Stack

HTML, CSS, Vanilla JavaScript, Node.js, Express.js, MongoDB Atlas, and Render.
